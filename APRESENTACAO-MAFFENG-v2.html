O Fluxo

O que acontece quando alguém envia

Quatro coisas acontecem automaticamente, em segundos, sem nenhuma intervenção manual da MAFFENG.

Passo 1
Candidato preenche o formulário
Nome, e-mail, telefone, área de interesse e currículo — tudo num só lugar, bonito e rápido
Passo 2
Dados salvos na planilha
Uma linha nova aparece no Google Sheets com todos os dados organizados e com data/hora
Passo 3
Currículo salvo no Drive
O arquivo PDF ou Word vai direto para uma pasta específica do Google Drive, com link na planilha
Passo 4
E-mail chega na hora
Um e-mail completo com todos os dados e o link do currículo chega imediatamente para a MAFFENG

O que foi usado

Quatro ferramentas. Zero custo extra.

Tudo integrado dentro do ecossistema que a MAFFENG já usa no dia a dia.

Site Estático

HTML, CSS e JavaScript puro. Sem servidor, sem mensalidade. Hospedado no GitHub Pages gratuitamente.

Google Apps Script

O cérebro do sistema. Recebe os dados do site, processa tudo e distribui para Sheets, Drive e e-mail.

Google Sheets

A planilha recebe uma linha nova a cada candidato. Nome, e-mail, área, data/hora e link do currículo.

Google Drive

Cada currículo enviado vai para uma pasta dedicada no Drive. Acessível de qualquer lugar, para sempre.
